# Security policy — X Messenger

Simple words. Please do not test with real secrets.

## Report a problem

- Open a private report: GitHub → Security → Report a vulnerability.
- Or email the owner via the address on the GitHub profile.
- Do NOT open a public issue for a suspected vulnerability.
- Do NOT include seed phrases, private keys, passwords, tokens, or real
  user data in any report. Use made-up test data only.

We will confirm receipt, investigate, fix, and credit you if you want.

## Supported versions

Only the latest commit on the remediation branch is supported for review.
There is no stable release yet. Do not use previews for valuable secrets.

## Rules for reports

- No network attacks against other users, no spam, no social engineering.
- Do not access other people's devices or accounts.
- Prefer proof with test data and exact steps to reproduce.

## After an audit

Once an independent audit is complete, its report and fixed findings will
be linked here with version numbers and hashes.
