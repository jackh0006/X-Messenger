# Contributing to X Messenger

## Build
```bash
npm ci
npm test
npm run build:web
npm run android:sync
```

## Rules
- Single source: edit root `index.html`, `app.js`, `core.js`, `style.css`. Never edit `www/` or `android/.../public/` by hand — they are generated by `build:web` + `cap sync`.
- Keep versions in lockstep (current stable, never hardcoded here): `package.json`, `android/app/build.gradle` (`versionCode`/`versionName`), `packaging/debian/DEBIAN/control`, `core.js VERSION`, in-app label. Enforced by `test/crypto.test.js`; bump via `scripts/release.sh`.
- Keep offline: no `fetch`, `XHR`, `WebSocket`, remote URLs, analytics, or new `INTERNET` permission. Run `npm test` (includes `test/offline.test.js`).
- Keep honest: no “unhackable / CIA / certified” claims in code, docs, or listings.

## Security reports
