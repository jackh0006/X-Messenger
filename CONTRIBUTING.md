# Contributing to X Messenger v1.0.0

## Build
```bash
npm ci
npm test
npm run build:web
npm run android:sync
```

## Rules
- Single source: edit root `index.html`, `app.js`, `core.js`, `style.css`. Never edit `www/` or `android/.../public/` by hand — they are generated by `build:web` + `cap sync`.
- Keep v1.0.0 fixed: `package.json`, `android/app/build.gradle` (`versionCode 1`, `versionName 1.0.0`), `packaging/debian/DEBIAN/control`, `core.js VERSION`, in-app `v1.0.0`.
- Keep offline: no `fetch`, `XHR`, `WebSocket`, remote URLs, analytics, or new `INTERNET` permission. Run `npm test` (includes `test/offline.test.js`).
- Keep honest: no “unhackable / CIA / certified” claims in code, docs, or listings.

## Security reports
Email jackh109867@gmail.com privately with version, impact, repro. Do not open public issues for vulns, phrases, or real ciphertext.
